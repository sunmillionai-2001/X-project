# X 私人选题雷达：实施与验收

日期：2026-10-04（北京时间）

## 交付内容

已实现独立的本机工作台，入口 http://127.0.0.1:8770 。没有改动已有视频工作台及其数据。源码在 `x-radar/`，数据在 `.x-radar/`，启动/停止入口在仓库根目录。

技术方案：Node.js 24 内置 HTTP 服务和 SQLite；原生 HTML/CSS/JavaScript 页面；sharp 将本机信息图渲染为 PNG。通过 AIHOT 公开 JSON API 读取线索，不部署完整 AIHOT 引擎、不复制其源码；附加信源支持 RSS/Atom 和 GitHub Releases JSON。模型通过用户配置的 OpenAI 兼容文本与图片接口调用。

功能覆盖：

- 当日精选复用、最多 5 个、不凑数、事件历史与新增事实判断。
- 主题查询、链接/文字输入、来源与发布时间展示。
- 选题角度与提纲确认、用户实测记录及截图。
- 800—1500 字初稿、正文修改及版本历史。
- 逐张修改配图方案、真实截图上传、PNG 信息图、原创插图服务适配。
- 正文变更撤销配图确认、项目恢复、复制与下载。
- 风格样本提炼与确认、模型设置、调用用量与估算费用记录。
- 近 7 天图文完成数和首次确认选题耗时，用于两周试用。

## 使用限制

- 只在电脑开启、本机服务运行时工作；不自动发布到 X。
- 链接读取是基本网页文字提取，登录页、反爬页面、部分 X 帖子可能需要用户粘贴文字。
- 新进展和写作角度依赖模型判断；原文读取不等于事实核验，生成内容需要用户审核。
- 初稿长度不符时不会覆盖正文，需检查模型设置后手动重试；付费失败调用也可能收费。
- 调用费用未知时不记成零；按单价计算的数值明确标记为估算。
- 密钥存于本机敏感配置文件，不做 Windows 凭据库集成；不可将该文件分享或提交到源码仓库。
- 选题计时包含页面停留；不追踪 X 曝光和互动。
