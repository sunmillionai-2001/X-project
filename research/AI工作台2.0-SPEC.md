# AI 工作台 2.0 SPEC

确认日期：2026-10-04。依据本次逐项问答，已授权实施。私人使用，不对外销售。

## Problem Statement
为抖音和 X 的 AI 自媒体运营提供个人创作环境，解决热点分散、选题难判断、制作步骤多、素材与复盘不连贯的问题。受众为对 AI 好奇的普通人，以及想用 AI 提效的人。

## Proposed Solution
在现有网页基础上融合 obsidian-creator-workbench 的素材、排期、方法论和复盘设计。推荐 3—5 个有来源的选题，允许查看全部。分阶段执行：确认选题 → AI 脚本与分镜 → 用户修改确认 → 收集素材并确认 → AI 中文配音与剪辑 → 人工预览 → 导出。

30—60 秒、9:16 解说视频。抖音和 X 共用视频，分别生成配文，提供抖音封面。发布包包含 MP4、封面、字幕和配文。用户手动发布并回填链接。截图识别和手工输入并存，识别数据确认后保存，未知数据为空。

素材不足或关键效果未验证时，暂停该选题，列明缺口并提供替代选题。原帖作为参考不等于素材授权。不可把新闻转述写成亲测。

## Technical Constraints
- Windows 本机运行，素材、任务、产物本地持久化；电脑关闭不执行。
- UTF-8 without BOM；修改后检查中文。
- 免费优先，付费调用默认关闭；已有会员不默认等于 API 权限。
- 优先复用开源组件，核对仓库、许可证、依赖、维护和真实运行情况。
- 纳入 cheat-on-content 与 dbskill；安装完整依赖引用，内容相关能力用于创作，商业模块不进入工作台。
- 保留当前草稿和设置，不覆盖现有数据库；升级可回退。
- 网络/API/模型不可用时展示真实错误，不能用模板结果冒充 AI 执行。
- 采集来源覆盖范围、采集时间、未知指标必须显示。单次热度不可伪装成增长趋势。
- 用户确认和任务版本绑定，修改稿件或素材后下游确认失效。

## Non-goals
不做销售、订单、客户管理、情感风险工具；不做直接自动发布、互赞、私信；不承诺全网热点覆盖、爆款或收益。第一版不做生成式视觉短片或实测录屏专用流程。不得绕过访问限制。

## Success Criteria
三个不同真实选题连续跑通脚本、素材、配音、剪辑和发布包导出；核对音频、中文字幕、画面匹配、30—60 秒时长、竖屏 MP4 可播放。完成复盘录入测试。真实账号发布及真实效果数据由用户提供，测试记录必须标记且不能混入真实统计。

## 实施顺序
1. 开源调研与依赖核实，安装两个技能包。
2. 本地执行服务、数据与状态机、网页 2.0。
3. 热点与素材采集、AI 脚本、配音、FFmpeg 成片。
4. 素材库、排期、复盘、截图识别及导出。
5. 三条内容验收与浏览器检查，记录未完成或依赖阻塞。
