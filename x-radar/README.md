# X 私人选题雷达

依据 [SPEC](../research/X私人选题雷达-SPEC.md) 制作的 Windows 本机网页工作台。只监听 `127.0.0.1:8770`，不连接 X 发布账号。

## 启动

双击仓库根目录 `启动X选题雷达.cmd`，或执行 `node start-x-radar.cjs` 后访问 http://127.0.0.1:8770 。启动器在后台启动服务，重复运行会复用现有服务。

需要 Node.js 24.11 或以上。信息图使用 sharp，当前电脑可使用 Codex 自带依赖；其他电脑可在本目录运行 `npm install`。

## 第一次使用

1. 打开“模型与风格”，填写自己的 OpenAI 兼容写作服务地址、模型和密钥。使用服务商支持的基础地址，工作台会拼接 `/chat/completions`；DeepSeek 可填 `https://api.deepseek.com`。没有模型配置时仍可浏览真实资讯，不能生成 AI 推荐和初稿。
2. 密钥只输入本机设置页，不要贴入聊天。服务地址和模型必须来自实际购买服务的说明；ChatGPT 订阅本身不是网页可用的模型 API 密钥。
3. 原创插图默认选择“ChatGPT 网页生成后导入”，无需图片密钥。图片 API 和费用估算默认收起。价格仅用于估算记账，留空不影响使用；实际 API 调用仍按服务商账单计费。币种仅标注单位，不做汇率换算。
4. 贴入 3—5 篇代表性帖子文字，保存、提炼、修改并确认风格说明。未确认时只使用基础风格。
5. AIHOT 已接入。在“少量一手来源”点击“添加一手来源”，填写名称、类型和地址。初始为空，避免替用户决定信源名单。配置数据的示例：

```json
[
  {"name":"Hugging Face 官方博客","kind":"rss","url":"https://huggingface.co/blog/feed.xml","enabled":true}
]
```

6. 回到“今日雷达”生成精选。当日再次打开会复用精选；无新内容不凑数。同一主题可在“主题与材料”随时查询。

## 内容方法

工作台已安装并适配 [cheat-on-content](https://github.com/XBuilderLAB/cheat-on-content) 和 [dbskill](https://github.com/dontbesilent2025/dbskill)。今日雷达的卡片会展示受众、阅读收益、材料依据和证据缺口；稿件页可以运行“内容审稿”，报告只引用正文原句，不覆盖你的文字。当前适配不执行完整盲预测、跨模型评分、T+N 复盘或阅读量预测，相关边界见 [技能安装说明](../research/X选题雷达-技能安装说明.md)。dbskill 按 CC BY-NC 4.0 仅用于本项目私人非商业范围。

## X 信号源

2026-10-05 新增，入口位于“今日雷达”下面。“已接入技能”保持最后。直接访问 `http://127.0.0.1:8770/#x` 也可打开。

1. 首批观察账号为鱼总聊 AI `AI_Jasonyu`、宝玉 `dotey`、`OpenAI`、`ChatGPT`。首次进入会读取公开帖子；以后同一天打开复用缓存，点击“刷新公开帖子”可手动更新。
2. 点“管理账号”，填 @用户名或 X 主页链接，备注名称选填；添加后点该账号“单独刷新”。最多 20 个账号，支持停用、重新启用和移出名单。停用账号保留缓存，不再参与采集和自动选题。
3. 用账号、发布时间、长文/长帖、引用帖筛选，也可搜索正文。默认按最新发布，支持按累计收藏、曝光和点赞排序。未知数字显示“—”，不表示零，也不表示新增流量。每次先显示 24 张卡片，按需加载更多。
4. 点封面或标题查看文字。引用内容单独注明原作者；只有预览的长文会明确标注，点“读取完整长文与串文”尝试补充正文与作者续帖。取得文字不代表事实已核实，串文也可能缺帖。
5. 最近 7 天的本人主帖与引用帖，自动与 AIHOT 和已配置的 RSS/GitHub 材料合并。每个账号最多 12 条 X 候选，兼顾最新和高收藏，全名单最多 48 条；普通回复、纯转发不单独进入选题池。模型输入中的长文可被截成节选，完整已采集正文留在 X 页面；写稿前需要读取原文。
6. “生成今日精选 / 重新筛选今日选题”使用当前来源进行 AI 推荐，最多 5 个、不凑数。已有今日精选不会因刷新帖子而消失；重新筛选保留已建立的稿件。“找选题”只针对当前帖子，结果进入“主题与材料”，再选择选题进入原有图文流程。

**刷新、浏览与补充公开文字不调用写作模型；生成或重新筛选选题会使用你已配置的写作 API。** 不需要 X 密钥，不要求登录个人 X，不读取密码、Cookie 或浏览器会话，不使用 X 官方开发者 API。

历史采集请求最近 12 天，最多 10 页/账号，两账号并发。每页实际返回数量由公共服务决定。分页达到时间边界也不能证明帖子齐全；重复游标、页数上限、结构异常、限流和失败分别记录。账号状态里可查看请求范围、本次取得数量、尝试时间和最近成功时间。失败时保留旧内容，明确标出旧快照；429 暂停后不继续重试。

纯图片帖子、带公开视频封面的帖子及无附言引用帖也会保留。排除记录会显示编号、原因和已确认的发布日期；已确认在请求时间范围外的记录不再把最近 12 天标成“部分取得”，日期无法确认的异常仍会提示缺口。

置顶按匿名主页的明确标记核对，单独展示原始发布日期与确认时间；未取得标记时显示“当前置顶未确认”，不会把搜索缓存当作确认。旧置顶不作为今天新热点。来源主体是 [FxEmbed](https://docs.fxembed.com/api/twitter/operations/2profilehandlestatuses/) 公开服务，辅以匿名 X 主页核对置顶；同一上游的不同接口不称为独立备用来源，不能承诺持续可用或全量覆盖。

当前 Windows 匿名主页、公开 JSON 接口请求可以复用系统里已启用的本机无凭据 HTTP/HTTPS 代理，不读取浏览器登录状态。也可通过 `XRADAR_PUBLIC_PROXY=http://127.0.0.1:端口` 指定本机代理，或设为 `off` 直接连接。没有可用网络时显示真实失败，不跳过证书验证或访问限制。封面和头像使用原帖的公开图片，由本机服务读取并缓存；只允许 X 图片域名，最多 4 个并发请求、24MB 内存缓存，浏览器缓存 6 小时。加载失败时显示文字卡片。

### 评论素材（2026-10-08 新增）

进入“X 信号源”，在页面上方“评论素材”区打开已保存的评论；或直接点击任意帖子卡片的 **评论素材**。详情顶部有“正文与串文／评论素材”两个页签，切到评论页即可点击 **补全公开评论**，无需滚到长正文末尾。工作台合并最新、高赞、搜索、图片评论与按日期查找的结果，沿回复关系确认主帖归属，去重后保存到本机 SQLite。采集不需要 X 登录、Cookie 或模型密钥，不调用写作模型。

- **继续补全评论**：从已保存的分页接着读，单轮最多 40 次请求、约 2 分钟，达到本轮边界不会删除已取得的评论。网络故障有一次重试，限流会暂停。
- **刷新评论／从最新重新检查**：重新检查公开内容，保留已保存的素材，同时记录发现的正文变化与指标快照。
- **最新优先／高赞优先**：查看不同评论；“再显示”只展开已保存数据，不重新采集。
- **复制评论素材**：保留评论作者、原文和主帖链接，可作为后续研究材料。尚未自动输入博主研究模型。
- **查看读取记录**：显示各路径页数、失败、实际取得数量和未确认上下文。来源计数与可采集记录口径不同，不以原帖计数承诺全部已取得。

评论每页保存，关闭网页后本机服务仍会继续当前任务。服务重启可保留已完成的页和检查点，重新打开帖子即可查看成果与继续采集。电脑关机期间不会持续采集；本功能未建立自动监测。

## 创作

选题卡片 → 确认角度与提纲 → 需要时自行实测并上传截图 → 生成/编辑/确认正文 → 生成/编辑/确认配图方案 → 制作图片 → 记录图文完成 → 手动复制、下载和发布。

原文可在稿件页点“读取原文”，也可手动补充证据。X 帖子链接通过 FxEmbed 读取公开帖子文字、长文和引用材料；其他网页做基本文字提取。不能保证所有 X 帖子和完整串文都可取得，不支持登录或绕过访问限制；失败时粘贴文字。读取成功仅代表已拿到文字，不等于已核实事实。原始发布时间未知时会明确标注。

正文建议 800—1500 字符，模型生成时目标为 1000—1200。初稿偏短或偏长也会保存，并显示实际字符数；可以手动修改，或点击“扩写到建议字数／精简到建议字数”，明确调用一次写作模型。每次修改保存历史版本；不会自动循环调用模型凑字数。模型返回空正文或错误格式时保留已有正文。

信息图由确认稿要点在本机渲染为 PNG。真实截图由用户上传，不用生成图冒充实测。修改正文会撤销配图确认并保留历史版本和素材。

### 使用现有 Plus 配图

1. 确认正文，生成配图方案；需要 ChatGPT 出图的位置选择“原创示意插图”，填写画面描述。
2. 确认方案，进入“制作配图”。点击该位置的“复制配图提示词”，再点“打开 ChatGPT”。
3. 在 ChatGPT 网页粘贴提示词，生成并下载图片到电脑。
4. 回到对应配图位置，选择下载的 PNG、JPG 或 WebP（最多 10MB），点击“导入这张插图”。图片会归入当前稿件，显示预览，可下载或替换；不会被当作实测截图，也不会撤销正文和方案的确认。
5. 方案中的图片都完成后，点击“图文完成，记录采用”。

网页出图使用你在 ChatGPT 中的账号和可用额度；工作台不登录该账号，也不会调用图片 API。信息图可以继续在本机一键制作。

以后需要 API 自动出图时，在设置中切换并保存“图片 API 自动生成”，展开 API 设置填写服务地址、模型和密钥。接口为 `/images/generations`，支持 base64 和公开 HTTPS 图片结果；异步轮询型图片平台暂不支持。

## 数据与费用

- 数据目录：仓库根目录 `.x-radar/`。SQLite 保存稿件和调用记录，`assets/` 保存图片。
- 密钥保存在该目录 `secrets.json`，不向浏览器回传。该文件是本机明文敏感配置，请避免共享。也可用 `XRADAR_TEXT_KEY`、`XRADAR_IMAGE_KEY` 环境变量提供密钥。
- 模型会收到本次生成需要的材料。保存于本机不代表推理离线。
- 每次模型调用先登记；失败或超时可能仍收费，不会自动重复调用付费接口。调用记录中 `pending` 可能表示服务在调用中重启、结果未知。
- 按单价和返回用量计算估算，未提供用量或单价时费用未知；图片按用户配置单价估算。最近 200 次显示在界面，全部记录保存在数据库。
- AIHOT 的 HTTP 结果遵循 Cache-Control/ETag 重新验证。推荐稿件是创作历史快照，并非完整公开资讯镜像，写作前仍应重新核实重要来源。
- 对同事件的新进展判断使用模型和来源指纹，不能保证完全识别所有换标题或新增事实；用户需核对推荐理由和新进展。
- 选题耗时记录从进入选题页到首次确认提纲，包括用户停留时间；不是精确的专注计时器。近 7 天目标完成数只计算明确标记完成的图文，不采集 X 数据。

## 停止、备份与检查

双击 `停止X选题雷达.cmd` 停止服务，停止器会核对进程是否属于本项目。关闭服务后复制整个 `.x-radar` 目录进行备份，包含 SQLite 和图片。不要分享密钥文件。

开发运行：`node server.mjs`；测试：`npm test`。隔离测试使用 `XRADAR_DATA` 和 `XRADAR_PORT`，不使用正式数据。`tests/x-browser-check.cjs` 检查 X 模块浏览器交互；加 `--live` 只浏览当前真实缓存，不生成付费选题。

实现为独立轻量工作台，没有复制 AIHOT 源码。通过 AIHOT 公开 API 获取私人非商业线索，保留来源；没有复用其名称或 Logo 作为本站品牌。

接口参考：[Chat Completions](https://developers.openai.com/api/reference/resources/chat)、[Images](https://developers.openai.com/api/reference/resources/images)、[AIHOT OpenAPI](https://aihot.news/openapi-v1.json)。不同兼容平台的参数与图片支持可能不同，需实际测试。
