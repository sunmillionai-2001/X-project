# X 私人选题雷达的技能使用

本目录用于普通受众的中文 X 中长文图文，依据已确认 SPEC 和用户指令工作。Windows 文本统一使用 UTF-8 without BOM，修改中文后重新读取。不要影响其他项目的数据、技能状态或数据库。

已安装技能位于项目根目录的 `.agents/skills/`：

- 选题与稿件的阅读回报：`dbs-content-value`。
- 已确定选题的表达结构：`dbs-content`；用户不需要先有产品。
- 原句级改稿诊断：`dbs-resonate`；检查模板化表达可用 `dbs-ai-check`，不能据此识别作者身份。
- 已有作品的传播机制分析：`dbs-spread`。
- 不确定用哪个入口时：`dbs`。
- 预测和复盘校准：完整 `cheat-on-content`。先检查本目录下是否已初始化，不读取其他项目状态；没有初始化时按上游流程开始，不假装已执行盲评分。

用户已经提供的定位、平台、内容形式与目标应复用，不重复询问。新增关键问题一次只问一个，提供编号选项。发布与数据回填保持人工操作。

X 公开内容采集的新约束（2026-10-05）：用户明确排除登录其个人 X 账号后采集的方式。不得要求其登录、提供密码、Cookie 或登录会话，也不得自动提取其浏览器会话。继续研究无需用户登录的公开来源；不使用 X 官方开发者 API。公共服务成功不代表自建成功，多种访问地址共用同一上游时不能称为独立备用来源。历史范围、缺失、采集失败和短期重复测试的局限必须如实展示。

网页运行规则见 `content-methods.md` 和 `content-methods.mjs`。它们提取所需方法并按 X 图文适配，不是完整技能执行器；需要明确报告哪些能力已在网页启用。
