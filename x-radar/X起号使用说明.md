# X 起号使用说明

打开工作台：<http://127.0.0.1:8770/#growth>，或点击左侧「X 起号」。

本模块服务于普通受众的 AI 热点、工具与玩法，中长文图文帖。复刻指借鉴内容组织方法，用自己的角度和事实写新帖。

## 1. 方法与文章

现在有 20 条方法、6 篇精选 X 原帖和从当前 X 缓存发现的最多 24 条候选。

- 按「定位、选题、复刻、图文、内容节奏、互动、复盘」筛选。
- 展开「查看做法与出处」，看具体步骤、证据来源和适用限制。
- 「标记已学」会保存在本机。
- 精选文章点击原帖核对；「选作结构参考」会送到复刻工作台。
- 候选是关键词筛出的待核对内容，不表示已经逐篇研究，也不代表完整覆盖 X。

## 低粉案例

新增 7 篇 AI 相关的低粉高表现样本。进入「低粉案例」即可查看，原来的方法和精选文章仍分别保留。

- 每篇显示采集时的粉丝、阅读、收藏、点赞和发布时间。粉丝数已在未登录 X 主页核对；阅读与互动来自 FxEmbed 公开服务。发帖时粉丝数未知。
- 展开卡片看读者任务、段落结构、可填空模板、短原句、图文观察与不能照搬的说法。拆解由 Codex 按 dbs-spread 方法整理，属于解释，不是流量预测。
- 普通帖对照优先选择同作者、同格式、前后 7 天的可取得主帖；不足 3 条不计算基线。不同题材、不同帖龄仍影响累计数字，不能据此证明哪个写法导致了高表现。
- 图文观察明确区分配图、文章封面和视频缩略图。本轮没有播放完整视频，也没有逐张检查长文的所有配图。
- 点击「使用这份拆解写新帖」进入复刻工作台，直接载入已保存的拆解，这一步不调用模型。填写自己的材料后，生成正文才会调用你配置的写作模型。也可以自行点击重新拆解。保存的参考原文可直接使用，不需要先把作者加入观察名单。

这批文章发布于 2026-09-01 至 2026-10-03，属于历史研究样本。作者与帖子的数据是保存时快照，不会因点击卡片自动刷新。先学习具体组织方式，再用自己的材料和真实发布数据检验效果。

## 2. 复刻工作台

1. 选择已取得的作者主帖，或粘贴至少 100 字参考原文。
2. 点击「拆解开头、结构与图文思路」。写作模型生成读者任务、3—6 个段落作用、填空模板、短原句依据和图文建议。
3. 写自己的主题、角度，以及至少 100 字的事实材料或真实观察。可粘贴公开资料，但应在文字中保留来源和限制。
4. 点击「生成原创正文与配图提示词」。输出 800—1500 字符中文单帖、2—3 个标题和 2—3 张配图提示词。
5. 核对、编辑、保存正文。引用的事实依据和借鉴说明属于生成版本；修改后需要重新检查。
6. 点击「转入我的稿件，继续配图」。依次确认提纲、正文和配图方案，然后使用图片 API 生成，或手动导入真实截图。

参考帖只用于结构，默认不会成为新帖的事实材料。正文事实来自你单独填写的材料；模型仍可能理解错误，原句检查不能代替事实核查。

模型遗漏字段或引用格式不正确时，系统最多额外调用一次写作模型补全并重新核对。两次仍不合格则不保存草稿；这次补全也会进入用量记录，可能计费。

转入稿件后，图文制作沿用原来的确认流程。改过正文会使原配图与正文的绑定失效，需要重新确认配图方案。重复点击转入会打开同一稿件。

## 3. 项目与 Skills

列出 11 个研究候选，每个都有 GitHub 地址、许可、核对日期、已读源码和固定版本链接。

- **已适配**：指定方法已进入本工作台的文字拆解、内容规划或配图提示词；不是部署整个上游应用。
- **解释已接入**：源码用于解释哪些互动信号参与评分；不据此给出精确算法权重。
- **仅研究**：已读相关源码，但没有安装或接入运行。

本轮适配 x-skills、X-growth-skills、宝玉 Skills 和 marketing skills 的相关方法。原有 cheat-on-content 与 dbskill 继续参与选题和审稿。已安装的原有技能仍在左侧最下方「已接入技能」。

## 4. 执行与复盘

完成起步清单，手动发布到 X，再填写公开帖子链接、发布时间、统计时间及已知数据。

- 不知道的指标留空，记录为「未知」；真实零值可以填 0。
- 记录显示帖龄，帮助在相近发布时长比较累计数据。
- 同一帖子可多次保存不同时间的数据快照。
- 收藏/阅读只在阅读大于 0、收藏已知时计算，表示观察比例。
- 归因关注新增只有能确认来自该帖时才填；否则留空。
- 每轮建议记录一个主要改动和观察结果，不把关联当作因果，不预测阅读量。

## 模型、费用与数据

结构拆解和原创写作使用「模型与风格」里配置的写作模型，实际模型名会在工作台显示；会把该步骤的材料发送给已配置的服务。

图片 API 使用你配置的生图服务，当前已实测 `gpt-image-2` 返回可保存图片。点击生图会实际调用服务，可能计费；并非使用 ChatGPT Plus 的网页额度。输入输出单价只用于本机估算，留空不影响使用，真实费用以服务商记录为准。

方法浏览、已学标记和人工数据记录不调用模型。正文、研究结果、进度与数据保存在 `.x-radar/radar.sqlite`；密钥另存于 `.x-radar/secrets.json`，不要分享这个文件。

本模块没有自动发布、自动回复、互关和登录采集。X 参考继续来自现有匿名公开信号源或你粘贴的材料，覆盖和长文缺口按实际情况标注。
