# 爆款创作

入口：工作台左侧「爆款创作」。研究报告和草稿保存在本机，输入框会在当前浏览器保留。

## 1. 研究博主

默认勾选余温（@gkxspace）、逸尘（@gengdaJ）、数字生命卡兹克（@Khazix0918）、鱼总聊 AI（@AI_Jasonyu）。每次可以选择 1—4 位，也可以从已经接入的 X 观察账号里选择其他人。

点击「研究当前样本」。如果材料太旧，先点击「刷新所选博主的公开帖子」。研究本身会调用你配置的写作模型；刷新公开帖子不调用写作模型。

每位至少需要 3 条近 12 天的文字主帖。通常选取最多 6 条近期文字主帖：高位、中间、低位和近期补充样本，再单独附上已取得的置顶参考。优先按收藏排序，数据不足时改用阅读或点赞；指标未知时不标高低。排名只在该作者已取得的样本中比较，帖龄和累计指标不同，不是账号所有历史内容的爆款榜。

报告包含表达风格、开头与结构、内容方法、可见运营线索，可以包含受众判断和样本对照。每条结论都有原帖和逐字原句。展开「查看原帖证据」核对；展开「样本与原文」能看到实际分析的文字。被引用作者的内容不会直接作为观察博主的风格证据，图片和未取得的全文也不会假装已读。

报告保存生成当时的样本、日期与指标，后续刷新来源不会偷偷改变旧报告。当前研究仍受公开来源的缺帖和时间窗口限制。方法解释属于文本推断，不能据此证明流量因果、收入、涨粉或保证下一篇会火。

## 2. 写自己的帖子

点击「参考这份研究写帖子」，或者切到「写自己的帖子」。

1. 选择研究报告，选择综合方法或其中一位博主的方法。
2. 填写主题，以及你自己的角度、判断或想让读者完成的动作。
3. 从公开帖子里选择最多 4 条事实材料；可以按账号、关键词筛选。也可以粘贴自己的原文、观察或经历。没有 X 材料时，至少补充 100 字的具体材料。
4. 点击「生成原创参考稿与配图提示词」。

研究报告负责提供通用结构与方法，事实材料负责提供本帖内容，两者分别使用。初稿包含 800—1500 字符的正文、2—3 个标题、提纲、借鉴方法说明、事实引用、核实提醒，以及 2—3 张原创示意图的提示词。没有提供的亲测、个人经历和数字不能凭空补写。

正文可直接修改、保存或复制。重新生成会保存成另一篇草稿。模型生成时会检查引用是否存在，并提示明显的较长文字重合；该检查不证明原创，也不识别 AI 作者。手动修改后，原来的来源与方法说明仍绑定生成稿，需人工重新核对。

## 3. 继续配图

现在可以直接在「爆款创作 → 写自己的帖子 → 配图制作」完成图片，无需先转入稿件。

- **使用 API 生成这张图**：自动生成、保存，并在当前页面显示预览和下载链接。
- **一键生成全部配图 / 生成剩余配图**：逐张生成，只补齐尚未保存的图片；中途失败时，已成功的图片会保留。
- **重新生成这张图（API）**：为当前提示词再生成一个版本，会再次调用接口，可能计费。旧版本可在历史图片中下载。
- **复制这张图的提示词 / 打开 ChatGPT 网页**：一直保留。网页生成后展开「网页生成后导入，或替换图片」，可直接导入到草稿。
- **查看或修改提示词**：可修改标题和画面要求，修改后点击「保存并确认配图提示词」。正文修改后也先核对提示词，再生成。

旧正文、旧提示词或之前版本的图片会保留在历史记录中，不混入当前配图。只有正文及对应提示词仍匹配的图片，才会随草稿进入稿件并复用。

点击「转入我的稿件，继续配图」。已有草稿不会因重复点击而重复创建稿件。

先确认角度与提纲，转入的正文会保留；然后核对正文并确认。正文保持原样时，配图方案直接复用已生成的提示词，不再调用写作模型；改过正文后会重新生成适合新正文的配图方案。

确认方案后，按「模型与风格」里选择的图片方式继续：

- **图片 API 自动生成**：点击「使用图片 API 生成」，生成后直接保存到稿件，不用复制提示词。服务地址、图片模型和图片密钥需要属于同一个服务商；第三方密钥使用该服务商提供的地址。
- **ChatGPT 网页生成后导入**：复制提示词到 ChatGPT 网页，用已有 Plus 生成，下载后导入对应位置。

在爆款创作中已经生成或导入的图片，转入稿件后无需重新制作；确认对应方案后可以直接查看。

图片设置提供「保存并生成测试图」，会真实调用一次图片模型，服务商可能计费；测试图单独保存，不会改变正文或审批状态。工作台显示最近一次生图测试的结果。若显示「当前密钥所属分组未开启图片生成」，需要在服务商后台切换到支持生图的分组，或联系服务商开通；接口地址和密钥已保存不代表生图权限已经开通。

仍然是人工确认和手动发布，不需要 X 账号登录。

### 当前图片模型

截至 2026-10-06，本机配置的云梦服务通过当前密钥返回 `gpt-image-2`。对 `gpt-image-2.5-sunburst` 和 `gpt-image-2.5-flare` 的实际请求均返回 404，没有可用渠道，因此当前继续使用已验证的 Image 2。

OpenAI 官方已经提供 [Image 2.5 Sunburst](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst) 和 [Image 2.5 Flare](https://developers.openai.com/api/docs/models/gpt-image-2.5-flare)。这说明官方模型存在，不代表第三方密钥有权限。工作台没有锁死 Image 2；服务商开放其他兼容模型后，可在「模型与风格」填写其支持的模型名并实测。

## 当前使用的方法

网页提取并适配已安装的 dbs-content、dbs-spread 等内容判断方法。dbs-content 用于结构与表达诊断，dbs-spread 用于有文本证据的传播机制分析；正文写作是工作台自己的能力。本模块没有执行完整的 cheat-on-content 初始化、盲预测、历史校准或流量预测。
