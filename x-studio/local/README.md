# 本机创作执行服务

运行 `python server.py`，默认仅监听 `127.0.0.1:8766`。浏览器入口同地址。
数据在项目外的 `.workbench-v2`，不会写入旧版数据库。通过 `WORKBENCH_DATA` 可指定隔离测试目录。
依赖见 requirements.txt。写稿模型使用本机 Ollama（127.0.0.1:11434）；未安装/未下载模型时明确返回错误，支持导出任务、导入真实 AI 结果。截图识别使用 RapidOCR，在本机执行，不上传图片。配音使用 edge-tts，失败不会以静音冒充成片。FFmpeg 由 imageio-ffmpeg 提供。

阶段确认绑定稿件与素材的版本。更新稿件、素材、声音会撤销成片审核。成片审阅后才能导出发布包。所有实际账号发布由用户手动完成。
